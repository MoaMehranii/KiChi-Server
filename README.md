# KiChi Server

KiChi Server v0.1 is the first step of an educational project aimed to build a distributed key-value server from scratch in Java.

Current Features:

- In-memory key-value storage
- Command pattern
- Parser
- Dispatcher
- Extensible command registry

Roadmap:

- TCP networking
- Thread Pool
- Persistence
- WAL
- Snapshot
- Replication
